Layout de Importação do SysPDV
Versão 15.1



1. Orientações para o correto preenchimento dos campos:

1. Campos de data devem ser preenchidos conforme a coluna formato indicado no layout.
2. Campos numéricos devem usar o PONTO(.) como separador de decimais da forma especificada na coluna formato.
3. Código de funcionário de 4 dígitos. Caso queira utilizar com 6 dígitos, o referido campo com esse tamanho encontra-se entre os últimos campos do registro.
4. Campos no formato numérico não contemplados pelo integrador devem obrigatoriamente está preenchidos com ZEROS.
