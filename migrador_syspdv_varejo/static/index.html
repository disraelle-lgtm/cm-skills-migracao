Migrador de Dados — SysPDV (Firebird) → VarejoFacil (PostgreSQL)

1. Conexões

Configuração do sistema onde o migrador está rodando.
Origem — SysPDV

Com instância, a porta é ignorada. O SQL Server é aberto só para leitura.

Firebird em Docker: use o caminho de dentro do container (ex.: /firebird/data/...).

Deixe o fbclient vazio: o migrador usa o client 64 bits da pasta windows\firebird_client_x64.

Destino — VarejoFacil (PostgreSQL)

2. Dados a serem migrados

Itens da pasta comandos/

Arquivos de troca de códigos — use as planilhas …_todos_…csv baixadas na seção 4. Consultar códigos (botão Download), depois do ajuste de códigos da migração inicial.

  • Clientes: se na migração inicial houve troca de códigos de clientes, anexe o arquivo cod_novo_cod_antigo_cliente_todos_…csv. Cliente, limite de crédito e contas a receber passam a ser gravados pelo código novo. Cliente novo com código ≥ 999999 ganha o próximo código vago.
  • Produtos: se na migração inicial houve troca de códigos de produtos, anexe o arquivo cod_novo_cod_antigo_produto_todos_…csv. Produto, preço, EAN, estoque e os demais itens de produto passam a ser gravados pelo código novo. Produto novo com código EAN ganha o próximo código vago e válido, e o EAN vira código de barras; produto de balança mantém o código.
  • Sem arquivo: o item roda como na migração inicial (ex.: só os produtos tiveram troca? anexe só o arquivo de produtos).
