Layout de Pré-venda/Pedido
Versão 19.0.0.20313



Considerações sobre o preenchimento dos campos:

1. Campos de data devem ser preenchidos conforme a coluna formato indicada no layout.
2. Campos numéricos devem usar o caractere PONTO (.) como separador de decimais da forma especificada na coluna formato.
3. Código de funcionário de 4 dígitos. Caso queira utilizar com 6 dígitos, o referido campo com esse tamanho encontra-se entre os últimos do registro.
4. Código da pré-venda de 9 dígitos. Caso queira utilizar com 10 dígitos, o referido campo com esse tamanho encontra-se entre os últimos do registro.
5. Campos no formato numérico não contemplados pelo integrador devem obrigatoriamente está preenchidos com ZEROS.
