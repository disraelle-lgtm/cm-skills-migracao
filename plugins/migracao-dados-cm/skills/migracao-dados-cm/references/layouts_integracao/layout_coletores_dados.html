Considerações iniciais: os campos não possuam delimitação inicial e final, visto que não são preenchidos com zeros para atingir a quantidade máxima permitida. Os campos gerados possuem como separador o ";" (ponto e vírgula).

Os arquivos dos coletores são nomeados em uma forma padrão, que permite a identificação completa de cada arquivo, bem como sua função ou versão. Esta nomenclatura deve seguir o seguinte modelo: Col_NNNN_AAAAMM_TXXVYYY.EEE onde:

Col:

 Significa arquivos de framework de coletor

NNNN:

 Significa o modelo do coletor o qual o framework pertence. Pois muitas vezes você terá o mesmo tipo de framework para dois ou mais modelos diferentes

AAAA:

 O ano que foi desenvolvido o framework. Este ano não deve mudar, a menos que uma nova versão do framework seja gerada.

MM:

 O Mês que foi desenvolvido o framework. Este deve seguir as mesmas regras do ano. TXX: Tipo do framework. Onde X é o numero do tipo. Ex T01. Para framework de tipo 1

VYYY:

 Versão deste tipo de framework. Onde YYY é um numero de versão. Ex: V102 para Versão 1.02

EEE:

 Extensão do arquivo

Exemplo de nome de arquivo de framework: Col_8300_200702_T1V100.AGX -> Para um framework do tipo 1 versão 1.00, criado para cypher 8300 em fevereiro de 2007.
Tipos de frameworks: Coletores Cypher tipo 1 e tipo 2.
