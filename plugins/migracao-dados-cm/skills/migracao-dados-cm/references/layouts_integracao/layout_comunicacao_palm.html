Layout Comunicação Palm Versão 2
Versão 15.1



Para a troca de informações entre SysPDV e PALM deverão ser gerados dois arquivos (PCPALM.TXT e PALMPC.TXT) conforme o layout especificado nas seções logo abaixo nesse documento.

Para geração dos arquivos deverão ser considerados os seguintes pontos:

1. Cada arquivo é composto por seções identificadas por uma palavra entre colchetes, semelhante aos arquivos .INI;
2. Cada seção deverá ser formada por vários campos separados por ”;” (ponto e vírgula) para maior economia de espaço seguindo a seqüência de campos definida no layout abaixo;
3. Os campos não devem ser preenchidos com espaços ou zeros para atingirem o tamanho indicado no documento. Este tem a função de limitador;

4. Não existe qualquer símbolo separador nos campos decimais de data ou hora.
5. Os campos data devem ser gerados no formado DDMMAAAA Exemplo: 20012006 = 20/01/2006;
6. Os campos numéricos terão os seus dois últimos caracteres considerados como decimais. Ex: 125630 = 1.256,00; Os campos com horas devem ser gerados no formato hhmm. Ex:1020 = 10:20; Segue abaixo exemplo de arquivo:
7. Caso o cliente escolha utilizar o serviços do SysPDV server a extensão para leitura é *.palm
